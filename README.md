# AiAppMaker（配布用）

AiAppMaker は、プログラムを書けない業務の担当者が、自分の会社の台帳や伝票のアプリを、自分のパソコンの上で使うためのソフトです。画面、帳票、集計、CSV と Excel の出力まで、1 つのソフトで使えます。データは、お使いのパソコンの中に置かれます。

このリポジトリは配布専用です。ソースコードは置いていません。使用許諾（LICENSE）と、版ごとの記録（CHANGELOG.md）を置いています。ダウンロードするファイルは、下のリリースのページにあります。

この版（v0.1.0）は、無料で使える最初の公開版です。

## はじめて開くときの警告について

この版には、開発元を Apple に確認してもらう署名がありません。そのため、はじめて AiAppMaker を開くと、macOS が警告を出します。

警告の題は「“AiAppMaker” は開いていません」です。

この警告は、AiAppMaker が危険だという意味ではありません。開発元の確認（Apple の署名と認証）を、受けていないためです。次の手順で、自分で「開いてよい」と macOS に伝えてください。この操作が要るのは、はじめの 1 回だけです。2 回目からは、ふつうにダブルクリックで開けます。

macOS の版によって、画面の文字が少し違うことがあります。この手順の文字は macOS 27 で確かめました。

### Mac で開く手順

1. ダウンロードした `AiAppMaker-0.1.0-macOS.dmg` をダブルクリックで開き、AiAppMaker をアプリケーションのフォルダへ入れる
2. アプリケーションのフォルダを開き、AiAppMaker をダブルクリックする。はじめに「“AiAppMaker” を検証中…」という小さなウィンドウが出ます。本体が大きいので、警告が出るまで数秒から十数秒かかることがあります。そのまま待ちます
3. 「“AiAppMaker” は開いていません」という警告が出る。本文は「Apple は、“AiAppMaker” に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。」です。ボタンは 2 つあります。目立つ青いボタンの「ゴミ箱に入れる」は押さず、その下の灰色のボタンの「完了」を押して閉じる
   - 「ゴミ箱に入れる」を押すと、AiAppMaker の本体がゴミ箱に入ります。押してしまったときは、ゴミ箱から戻すか、もう一度入れ直します
4. 画面の左上のアップルのマークから「システム設定」を開き、左の一覧の「プライバシーとセキュリティ」を押す
5. 右の画面を下へ動かし、「セキュリティ」の欄を見る。「お使いの Mac を保護するために “AiAppMaker” がブロックされました。」という文と、「このまま開く」のボタンが出ているので、「このまま開く」を押す
   - この表示は、しばらくすると消えます。消えたときは、手順 2 のアプリを開くところからやり直します
6. パスワード（Mac を使うときのパスワード。Touch ID のときは指紋）を求められたら、入れる
7. 確認の画面が出たら、「このまま開く」を押す

これで AiAppMaker が開きます。

### Windows で開く手順

Windows 版にも、開発元の署名がありません。そのため、はじめて開くと、Windows が青い画面で警告を出します（SmartScreen という、Windows の確認の仕組みです）。

この警告は、AiAppMaker が危険だという意味ではありません。開発元の署名を、まだしていないためです。次の手順で、自分で「実行してよい」と Windows に伝えてください。この操作が要るのは、はじめの 1 回だけです。

Windows の版によって、画面の文字が少し違うことがあります。この手順の文字は Windows 11 で確かめました。

1. ダウンロードした `AiAppMaker-0.1.0-Windows.exe` をダブルクリックする
2. 青い画面に「Windows によって PC が保護されました」と出る。本文は「Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC が危険にさらされる可能性があります。」です。この時点のボタンは「実行しない」だけなので押さず、本文の下の「詳細情報」を押す
3. 「アプリ: AiAppMaker-0.1.0-Windows.exe」「発行元: 不明な発行元」と出て、「実行」と「実行しない」のボタンが出る。「実行」を押す
4. 入れる場所などを選ぶ画面は出ません。そのまま入り、入れ終わると AiAppMaker が自動で開きます。デスクトップにも、ショートカットができます

入れるのは、いま使っている利用者のぶんだけです。管理者の許可の確認は出ません。2 回目からは、デスクトップのショートカットをダブルクリックして開きます。

### ダウンロードした物が本物かを確かめたいとき

操作に慣れていない方は、この節を飛ばして構いません。

リリースのページに、`SHA256SUMS.txt` というファイルがあります。ダウンロードしたファイルの「指紋」（SHA-256 という、ファイルの中身から計算した長い英数字）が書いてあり、これと自分の手元のファイルの指紋が同じなら、途中で書き換えられていません。

#### Mac の場合

1. ターミナルを開く（アプリケーションの「ユーティリティ」の中にあります）
2. 次の 2 行を入れて、Return キーを押す（ダウンロードしたのが「ダウンロード」フォルダのときの例です）

```
cd ~/Downloads
shasum -a 256 AiAppMaker-0.1.0-macOS.dmg
```

3. 出てきた長い英数字を、`SHA256SUMS.txt` の同じファイル名の行の英数字と見比べる。同じなら、本物です

#### Windows の場合

1. 画面の下の「スタート」（Windows 11 では真ん中、Windows 10 では左端）を押し、「PowerShell」と入力して、出てきた「Windows PowerShell」を開く
2. 次の 2 行を入れて、Enter キーを押す（ダウンロードしたのが「ダウンロード」フォルダのときの例です）

```
cd ~\Downloads
(Get-FileHash AiAppMaker-0.1.0-Windows.exe -Algorithm SHA256).Hash
```

3. 出てきた長い英数字を、`SHA256SUMS.txt` の同じファイル名の行の英数字と見比べる。同じなら、本物です。大文字と小文字の違いは、気にしなくて構いません

## 無料版でできること

この版は無料で、業務にも使えます。次の機能が使えます。

- 画面（登録、一覧、詳細、ホーム）、伝票と明細、マスタ、計算の項目
- 集計表、縦横の表、工程表とカレンダー
- 帳票の印刷と PDF、CSV と Excel の出力、Excel と CSV からの取り込み
- 締め処理、状態の流れ、項目の暗号化
- バックアップと、設計の版の復元
- サンプルのデータの追加と削除

見本の 8 本は、この版で使える機能だけで作ってあり、見本の中の機能は全部動きます。

### この版で使えない機能

次の機能は、この版では使えません。画面に出ないか、押せません。

- 承認（申請、承認、却下の流れ。画面では「承認」と出ます）
- 共有（同じ会社のパソコンどうしで、1 つのアプリのデータを使い合う機能。画面では「共有と接続」と出ます）
- 利用者の管理（画面では「ログインと利用者の管理」と出ます）
- ログイン（画面では「ログインと利用者の管理」と出ます）
- 作ったアプリの書き出し（画面では「コードの書き出し」と出ます）
- AI で作る機能（無料版では AI で作る機能は使えません。設定からもオンにできません）

項目を画面で伏せる機能（伏せ字）は、ログインを有効にしたアプリでだけ働きます。この版はログインを閉じているので、伏せ字は画面に効きません。守りたい項目は、項目ごとに暗号化を選んでください。

### 白紙からは作れません。見本を取り込んで使います

AI が使えないため、この版には、白紙から新しい表や項目を作る画面がありません。代わりに、業種ごとの見本のアプリが 8 本入っています。見本を取り込むと、表、画面、帳票、サンプルのデータまで入った状態で始められます。画面や帳票の見た目は、見本を取り込んだあとで組み替えられます。見本に表や項目を足すことは、この版ではできません。

## 見本のアプリ（8 本）

新しいアプリを作る画面で、見本を選んで取り込みます。見本ごとに、どんな業務の見本かを説明する文が付いています。取り込むと「はじめに」の表が付き、順に試せます。試し終えたら、サンプルデータの削除で、見本の行を消せます。

| 見本 | 一言 |
|---|---|
| 工務店の見積から請求まで | 見積から工事、請求、入金までを記録します |
| 工事日報 | 現場ごとの日々の作業と人工を記録します |
| 取引先と売掛・入金 | 取引先の連絡と請求、入金、延滞を記録します |
| 備品の貸出台帳 | 備品の貸出と返却の日付を記録します |
| サロンの予約表 | スタッフごとの予約を時刻の表で管理します |
| 商品の入出庫と在庫 | 入庫と出庫を記録して現在庫を見ます |
| 個別指導の授業予定と出欠 | 講師と教室と生徒の重なりを防ぐ時間割 |
| 設備の日常点検表 | 設備と日付ごとの点検結果を表で入れます |

見本のサンプルの会社名や住所などは、作り物です。自分の会社の情報に書き換えて使ってください。

見本ごとの制限（例: 在庫が足りなくても出庫を登録できる）は、各見本の詳細の画面の「この見本でできないこと」に出ます。「この見本でできないこと」に収まらない件は、見本の「はじめに」の表に書いてあります（例: 工務店の見本の、工事の一覧に出る列）。

お金や集計に効く 5 つの状態（工事日報の確認済、サロンの会計済、取引先の入金済、在庫の入荷済、個別指導の授業料の入金済）の行は、詳細から削除できません。間違えたときは、取消の移りか、前の状態へ戻す移りで直します。サンプルデータの削除では、これらの行も消せます。

見本を取り込むとき、「新しいアプリ」を作った直後のフォルダなら、そのまま取り込めます。「このフォルダには見本を取り込めません」と出て、押し直しのボタンが無いときは、画面の上の「新しいアプリ」から、別の名前か別の場所で作り直してください。

## データについての注意

この版は最初の公開版です。今後の版では、登録したデータを引き継げない場合があります。大事なデータは、一覧の「CSV・Excel に出力する」で保存しておいてください。

アプリを開いたときに行が 0 件になっていて、消した覚えがないときは、何も登録せずに閉じて、下の「問い合わせ」に連絡してください。

データは、お使いのパソコンの中に置かれます。新しいアプリの置き場所の初めの候補は、書類（Windows ではドキュメント）フォルダの中の aiappmaker フォルダです。

### 同期するフォルダにはアプリを置かないでください

iCloud、OneDrive、Dropbox、Google ドライブなど、同期するフォルダにはアプリを置かないでください。アプリのデータは、使っている間、何度も書き換わります。同期の仕組みが同時にそのファイルを書き換えると、データが壊れることがあります。

2 台のパソコンで同じアプリを同時に開くこともしないでください。片方の変更が消えたように見えることがあります。アプリは、作ったパソコンで使ってください。別のパソコンへ移すと、暗号化の項目があるアプリ（見本では、工務店とサロンのアプリ）は、そのままでは開けません。暗号化の項目が無く、暗号化した値も残っていないアプリは、別のパソコンへ移して最初に開いたときだけ、そのパソコンの新しい鍵に替えて開き、画面の上に 1 度だけ知らせが出ます。そのあとは、前のパソコンへ戻す、2 台で交互に開く、さらに別のパソコンへ移すのどれでも、開かずに止めて手順を出します（下の「別の PC へ移したアプリが開けないとき」を見てください）。

気を付けたいのは、書類フォルダ自体が同期の対象になっている場合です。

- Mac で iCloud の「デスクトップと書類フォルダ」を使っている場合
- Windows で OneDrive のバックアップにドキュメントフォルダを入れている場合

この設定を使っていると、初めの候補の書類（ドキュメント）フォルダも、同期の対象になります。

新しいアプリを作るときに、置き場所を変えられます。

1. 「何をしますか？」の画面で「新しいアプリ」を押す（アプリを開いているときは、画面上部のメニューにも「新しいアプリ」があります）
2. 「保存先」を押して開く
3. 出ている置き場所を見て、同期するフォルダなら、「ほかの場所を選ぶ」を押して、同期しないフォルダ（例: ホームの直下に作ったフォルダ）を選ぶ
4. アプリ名を入れて、「見本から始める」を押し、見本を選んで「この見本で始める」を押す

同期フォルダらしい場所を選ぶと、作成の画面の「保存先」の欄の下に知らせが出ます。例: 「「iCloud Drive」の同期フォルダかもしれません。データが壊れないよう、「保存先」を開いて場所を変えてください。」。「iCloud Drive」の所には、見つかった同期サービスの名前が入ります。場所の名前に、同期サービスの名前を含むだけの場所（利用者の名前が icloudfan など）では出ません。選んだ場所は、見本の一覧へ移って戻っても、そのまま残ります。見分けられない場所もあります（Mac の iCloud の「デスクトップと書類フォルダ」、Windows の Google ドライブなど）。出ないときも、手順 3 のとおり、置き場所を確認してください。

すでに同期するフォルダに作ったアプリがある場合は、次の手順で移してください。

1. AiAppMaker を閉じる
2. アプリのフォルダごと、同期しない場所へ移す。中のファイルを選んで移さず、必ずフォルダごと移します（画面に見えないフォルダにも、データの鍵が入っています）
3. AiAppMaker を開き、「何をしますか？」の画面の「ほかの場所から選ぶ」で、移した先のフォルダを選ぶ

移す前の場所は、「最近開いたアプリ」に「見つかりません」と残ります。行の横のボタンで、一覧から消せます。

開いたあとに行が 0 件になっていたら、または「データのファイルが見つからないか、中身が空です」と出たら、何も登録せずに AiAppMaker を閉じてください。データのファイル（data.sqlite）が移せていません。元の場所の data.sqlite で、移した先の同じ名前のファイルを置き換えてください。

次のどれかのときは、鍵のファイルが移せていません。
- 「このアプリのデータには、暗号化した項目の値が入っていますが、鍵のファイルが見つかりません」と出た
- 「暗号化した項目の鍵のファイルが見つかりません」と出た
- 暗号化の項目が「enc:」で始まる文字で出ている

何も登録せずに閉じて、フォルダごと移し直してください。

### データのファイルが壊れたとき

画面に「データのファイルが壊れていて、開けません」と出たときの手順です。AiAppMaker は、壊れたファイルを書き換えていません。

#### 画面から戻す

この版では、データのファイルが壊れて開けないと AiAppMaker が判断したときに、アプリのウィンドウの失敗の画面（赤い文と「もう一度読む」のボタンが出ている画面）に、「バックアップから戻す」のボタンが出ます。失敗の画面でも、ボタンが出ないことがあります（データのファイルが壊れているのかを判断できないときなど）。ボタンが出たときに、バックアップのファイルがあれば、このボタンで戻せます。

1. 「バックアップから戻す」を押す
2. バックアップのファイルを選ぶウィンドウが開く。初めは、自動で取ったバックアップが入るフォルダ（アプリのフォルダの中の見えないフォルダ「.aiappmaker」の中の「backups」）で開く。自分で取ったバックアップは別の場所にあるので、置いた場所を開いて選ぶ。選べるのは、どこにあるファイルでもよく、AiAppMaker は、どのアプリで取ったバックアップかまでは確かめません。必ず、このアプリで取ったバックアップを選んでください。ほかのアプリのバックアップを選ぶと、このアプリのデータが、そのアプリのデータに置き換わってしまうことがあります
3. ファイルを選ぶと、「いまのデータを、バックアップしたデータで置き換えます」という確認が出る。壊れたファイルを残すフォルダも、ここに書いてある。戻すなら「戻す」、やめるなら「やめる」を押す。やめたときは、何も変わらない
4. 「バックアップから戻しました」と出たら、「画面を開く」を押す。「戻す前のファイルは「…」に残しました」と、残したファイルの名前が出る

戻す前の壊れたファイルは、消さずに、「.aiappmaker」の中の「backups」に、名前が「data-」で始まるファイルとして残ります。同じフォルダに「data.sqlite-journal」などの付属のファイルがあれば、一緒に残します。

選んだバックアップが、別の鍵で作られたもの、締めた期間と合わないもの、アプリの定義と合わないもの、壊れているものだったときは、理由が出て、いまのデータのファイルは変えません。戻したあとも、画面の上に赤い失敗の文と「もう一度読む」が残ることがあります。「画面を開く」を押すと、戻したデータで開きます。

ボタンが出ないとき（データのファイルの一部だけが壊れているときなど）と、画面から戻せなかったときは、次の手作業で戻してください。手作業は、鍵と締めた期間の確かめをしません。

#### 手作業で戻す

バックアップのファイルがあれば、次の手順で戻せます。

1. アプリを閉じる
2. このアプリのフォルダにある「data.sqlite」を別の場所へ移す（フォルダの場所は「最近開いたアプリ」の行に出ています）。同じフォルダに「data.sqlite-journal」があれば、それも一緒に移します
3. バックアップのファイルをそのフォルダに置いて、名前を「data.sqlite」にする（Windows で名前の最後の「.sqlite」が見えないときは、エクスプローラーの「表示」で「ファイル名拡張子」をオンにしてから名前を変えます）

バックアップのファイルは、次の場所を探してください。

- 自分で取ったバックアップ: 初めの置き場所は書類（Windows ではドキュメント）フォルダで、名前は「アプリ名-日付.sqlite」です
- 自動で取ったファイル: アプリのフォルダの中の見えないフォルダ「.aiappmaker」の「backups」に、操作の前に自動で取ったファイル（名前が before- か data- で始まる）が残っていることがあります。Mac の Finder は、Command + Shift + ピリオドで見えないフォルダを出します。Windows はそのまま見えます
- パソコン全体のバックアップや、同期サービスの履歴

「data-key」で始まる名前の鍵のファイルは触らないでください。見つからないときは、下の「問い合わせ」に連絡してください。

### データのファイルが見つからないとき

画面に「データのファイルが見つからないか、中身が空です」と出たときの手順です。以前はデータがあったアプリで、データのファイル（data.sqlite）が無いか、空になっているときに出ます。空のデータで始めると全部消えたように見えるので、ここで止めています。AiAppMaker は何も書き換えていません。データのファイルが無いあいだは、アプリの設計を変える操作（項目の削除、前の版への復元など）も、何も変えずに止まります。

同期するフォルダから消えたときは、先に同期サービスの履歴と、削除したファイルの置き場を見てください。

データを取り戻す手順です。

1. アプリを閉じる
2. このアプリのフォルダに空の「data.sqlite」があれば、別の場所へ移す（フォルダの場所は「最近開いたアプリ」の行に出ています）。同じフォルダに「data.sqlite-journal」があれば、それも一緒に移します
3. 元のファイルかバックアップのファイルをそのフォルダに置いて、名前を「data.sqlite」にする（Windows で名前の最後の「.sqlite」が見えないときは、エクスプローラーの「表示」で「ファイル名拡張子」をオンにしてから名前を変えます）

バックアップのファイルの探し場所は、上の「データのファイルが壊れたとき」と同じです。データのファイルが無いあいだは、アプリの画面が開かず、「設定・保守」の「バックアップから戻す」には進めません。バックアップのファイルがあるときは、この手順で戻してください。

データを捨てて、空のデータで使い始める手順です。探し終えてから行ってください。

1. アプリを閉じる
2. アプリのフォルダの中の見えないフォルダ「.aiappmaker」にある「data-made」を、消さずに「data-made-old」に変える。Mac の Finder は、Command + Shift + ピリオドで見えないフォルダを出します。Windows はそのまま見えます
3. もう一度開く

名前は、頭の「data-made」を残して、最後にハイフンで「-old」を付けてください。ほかの名前に変えると、AiAppMaker が印を移したと判断できないことがあります。「data-key.enc」は変えないでください。

### 別の PC へ移したアプリが開けないとき

アプリのフォルダを別のパソコンへ移したあとに、アプリが開けないときの手順です。データの鍵は、アプリを作ったパソコンの中で守られています。そのため、アプリのフォルダを別のパソコンへ移すと、その鍵が使えません。データは書き換えられていません。

暗号化の項目が無く、暗号化した値も残っていないアプリは、アプリのフォルダごと別のパソコンへ移して最初に開いたとき、そのパソコンの新しい鍵に替えて開きます。そのとき、画面の上に「この PC では開けない鍵だったので、この PC の鍵に替えました。ほかの PC で開くと止まります。2 台で同じフォルダを使うと、変更が消えることがあります」と、1 度だけ出ます（「閉じる」で閉じます）。前の鍵は、見えないフォルダ「.aiappmaker」の中に、「data-key.enc.」で始まる名前のファイル（日時が付いた「data-key.enc.unreadable-…」など）で残ります。このファイルは消さないでください。Mac の Finder は、Command + Shift + ピリオドで見えないフォルダを出します。Windows はそのまま見えます。

暗号化の項目が 1 つでもあるアプリと、暗号化した値がデータに残っているアプリ（前に暗号化していた項目を、あとで消した場合など）は、この自動の入れ替えはせず、開かずに止めます。

暗号化の項目があるアプリなど、自動で替えないアプリは、開かずに止めて、次の文のどれかを出します。出た文に合う、下の項目を読んでください。

- 「暗号化した項目の鍵を、この PC では取り出せません」か「暗号化した項目の鍵のファイルが見つかりません」
- 「このアプリのデータには、暗号化した項目の値が入っていますが、鍵のファイルが見つかりません」
- 「この PC では開けない鍵に替わっています」

名前を変えるとき、拡張子を変えてよいかを聞かれたら、変える側のボタンを押してください（Mac は「“.enc-old”を使用」のように「使用」の付いたボタン、Windows は「はい(Y)」）。Mac では、聞かれずにそのまま変わることもあります。

#### 「暗号化した項目の鍵を、この PC では取り出せません」か「暗号化した項目の鍵のファイルが見つかりません」と出たとき

暗号化の項目があるアプリを別のパソコンへ移したときに出ます。同じパソコンでも、AiAppMaker の設定のフォルダ（Windows では、その中の「Local State」というファイル）を失ったときや、Mac のキーチェーンの項目を削除したときも、同じ文が出ることがあります。同じパソコンでも、鍵のファイルを消すか移すと、「暗号化した項目の鍵のファイルが見つかりません」と出ることがあります。

「鍵のファイルが見つかりません」と出たときは、まず鍵のファイル「data-key.enc」を、アプリのフォルダの中の見えないフォルダ「.aiappmaker」に戻せないかを確かめてください。

アプリを作ったパソコンが使えるときは、そのパソコンで、作ったときと同じ利用者で開いてください。

そのパソコンが使えないときは、「.aiappmaker」にある「data-key.enc」と「data-made」を、消さずに別の名前に変えると開けます。片方が無ければ、ある方だけ変えます。名前は、頭の「data-key」「data-made」を残して、最後にハイフンで「-old」を付けてください（「data-key.enc-old」「data-made-old」。ピリオドではなくハイフンです）。ほかの名前に変えると、AiAppMaker が鍵を移したと判断できず、止まることがあります。

- 暗号化の項目があるアプリ（見本では、工務店の見積から請求までの協力会社の「口座番号」と、サロンの予約表の顧客の「アレルギーと肌トラブルの注意」が、初めから暗号化されています）は、その項目が読めず、「enc:」で始まる文字で出ます。その文字を書き換えないでください。この状態で新しく登録した行の暗号化の項目は、あとで元の鍵に戻すと読めなくなります
- 暗号化の項目が無く、暗号化した値も残っていないアプリで、この文が出たときも、これでふつうに使えます（ふつうは、この手順の前に自動で開きます）

作ったパソコンが直るかもしれないときは、先に下の「問い合わせ」に連絡してください。

#### 「このアプリのデータには、暗号化した項目の値が入っていますが、鍵のファイルが見つかりません」と出たとき

データのファイル「data.sqlite」だけを、別の場所や別のパソコンへ移したときに出ます。新しい鍵は作らず、ここで止めています。データは書き換えていません。暗号化していない項目も、今は開けません。

元のアプリのフォルダごと移し直してください。見えないフォルダ「.aiappmaker」に鍵が入っているので、Mac の Finder で見えないフォルダも一緒に移します。

元のフォルダが見つからないときは、暗号化した項目は読めなくなるのを承知で、次の手順で開けます。

1. AiAppMaker を閉じる
2. アプリのフォルダの中の「.aiappmaker」を開く（Mac では見えないフォルダです。Command + Shift + ピリオドで出します）
3. その中に新しいフォルダを作り、名前を「data-made-old」にする
4. もう一度アプリを開く

「.aiappmaker」が無いときは、この手順は取れません。下の「問い合わせ」に連絡してください。

#### 「この PC では開けない鍵に替わっています」と出たとき

暗号化の項目が無く、暗号化した値も残っていないアプリを、一度、別のパソコンへ移して開いて鍵を替えたあとで出ます。前のパソコンへ戻す、2 台で交互に開く、さらに別のパソコンへ移す（買い替えの 2 度目も）のどれでも、止まります。同じパソコンでも、AiAppMaker の設定のフォルダ（Windows では、その中の「Local State」というファイル）を失ったときや、Mac のキーチェーンの項目を削除したときに出ることがあります。データは書き換えられていません。

次の手順は、暗号化の項目が無く、暗号化した値も残っていないアプリの分です。移したあとに暗号化の項目を足していたときは、この手順を使わず、下の「問い合わせ」に連絡してください（この場合は、画面の文が、ここに書いた文と別の文になることもあります）。

AiAppMaker を閉じてから、画面の文に合わせて、次のどちらかを行ってください。

- 文に「この PC の前の鍵は「…」です」と名前が出たとき: 「.aiappmaker」の「data-key.enc」の名前を、文に出た空きの名前（「data-key.enc.old」など）に変えます。そのあと、文に前の鍵として出た名前のファイルの名前を「data-key.enc」に変えます。2 つとも変えてから開いてください
- 名前が出ないとき（このパソコンで開ける前の鍵が無いとき）: 「.aiappmaker」の「data-key.enc.」で始まるファイルを、消さずに、アプリのフォルダの外へ移してから開きます。「data-key.enc」は移しません。開くと、このパソコンの新しい鍵に替えて開きます

前の鍵に戻したいときがあります。前のパソコンで取ったバックアップに暗号化した値が入っていて、前の鍵で読みたいときです。そのときは、前の鍵を作ったパソコンで、作ったときと同じ利用者でアプリを開きます。上の「この PC の前の鍵は「…」です」の文で、戻す名前が出ます。移した先のパソコンで暗号化の項目を足していたときは、戻さずに下の「問い合わせ」に連絡してください。AiAppMaker の設定のフォルダを失ったあとは、同じパソコンでも前の鍵は開けません。
