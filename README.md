# AiAppMaker（配布用）

AiAppMaker は、会社の台帳や伝票を、自分のパソコンの上で使うためのソフトです。見積、日報、貸出、在庫、予約などを、入力の画面と印刷の帳票つきで管理できます。プログラムを書く必要はありません。データは、お使いのパソコンの中に置かれます。

この版（v0.2.0）は、無料で、業務にも使えます。前の版（v0.1.0）からの変更は、[更新の記録（CHANGELOG.md）](CHANGELOG.md)にあります。

## できること

- 登録、一覧、詳細の画面と、ホーム画面
- 集計表、縦横の表、工程表、カレンダー
- 帳票の印刷と PDF、CSV と Excel の出力、Excel と CSV からの取り込み
- バックアップ

この版では、表や項目を新しく作る画面はありません。業種ごとの見本のアプリ（8 本）を取り込んで使います。画面や帳票の見た目は、取り込んだあとで組み替えられます。

承認や共有など、この版で使えない機能は、[くわしい情報](くわしい情報.md#この版で使える機能と使えない機能)にあります。

## はじめて開くときの警告について

この版には、開発元を確かめるための印（署名）が、まだ付いていません。そのため、はじめて開くときに、macOS と Windows が注意の画面を出します。AiAppMaker が危険だという意味ではありません。次の手順で、自分で「開いてよい」と伝えてください。この操作が要るのは、はじめの 1 回だけです。2 回目からは、ふつうに開けます。

画面の文字は、OS の版によって少し違うことがあります。この手順は、macOS 27 と Windows 11 で確かめました。

### Mac で開く手順

1. ダウンロードした `AiAppMaker-0.2.0-macOS.dmg` をダブルクリックで開き、AiAppMaker をアプリケーションのフォルダへ入れる
2. アプリケーションのフォルダで、AiAppMaker をダブルクリックする。「“AiAppMaker” を検証中…」という小さなウィンドウが出て、警告が出るまで数秒から十数秒かかることがあります。そのまま待ちます
3. 「“AiAppMaker” は開いていません」という警告が出る。ボタンは 2 つあります。青い「ゴミ箱に入れる」は押さず、その下の灰色の「完了」を押して閉じる
4. 画面の左上のアップルのマークから「システム設定」を開き、左の一覧の「プライバシーとセキュリティ」を押す
5. 右の画面を下へ動かし、「セキュリティ」の欄を見る。「お使いの Mac を保護するために “AiAppMaker” がブロックされました。」と出ているので、「このまま開く」を押す
   - この表示は、しばらくすると消えます。消えたときは、手順 2 からやり直します
6. パスワード（Mac を使うときのパスワード。Touch ID のときは指紋）を求められたら、入れる
7. 確認の画面が出たら、「このまま開く」を押す

これで AiAppMaker が開きます。「ゴミ箱に入れる」を押してしまったときは、[困ったとき](困ったとき.md#ゴミ箱に入れるを押してしまったとき)を見てください。

### Windows で開く手順

1. ダウンロードした `AiAppMaker-0.2.0-Windows.exe` をダブルクリックする
2. 青い画面に「Windows によって PC が保護されました」と出る。このときのボタンは「実行しない」だけなので押さず、本文の下の「詳細情報」を押す
3. 「アプリ: AiAppMaker-0.2.0-Windows.exe」「発行元: 不明な発行元」と出て、「実行」と「実行しない」のボタンが出る。「実行」を押す
4. 入れる場所などを選ぶ画面は出ません。そのまま入り、入れ終わると AiAppMaker が自動で開きます。デスクトップにも、ショートカットができます

管理者の許可の確認は出ません。2 回目からは、デスクトップのショートカットをダブルクリックして開きます。

お使いのウイルス対策ソフトが、誤って警告を出すことがあります。そのときも、ダウンロードは、このページからだけにしてください。

## はじめかた

見本を 1 つ開くまでの手順です。

1. 上の手順で AiAppMaker を開く
2. 「何をしますか？」の画面が出る。「新しいアプリ」を押す
3. アプリ名を入れて、「見本から始める」を押す
4. 見本の一覧から、近い業務の見本を選び、「この見本で始める」を押す
5. 取り込みが終わると、AiAppMaker の画面に戻る。画面の上の「アプリを開く」を押すと、見本のアプリが開きます。左のメニューの「はじめに」に、試す順番が書いてあります。サンプルのデータが入っているので、登録や印刷を試せます

見本は、次の 8 本です。取り込むと、表、画面、帳票、サンプルのデータまで入った状態で始められます。サンプルの会社名や住所などは、作り物です。試し終えたら、サンプルデータの削除で、見本の行を消せます。

| 見本 | 一言 |
|---|---|
| 工務店の見積から請求まで | 見積から工事、請求、入金までを記録します |
| 工事日報 | 現場ごとの日々の作業と人工を記録します |
| 取引先と売掛・入金 | 取引先の連絡と請求、入金、延滞を記録します |
| 備品の貸出台帳 | 備品の貸出と返却の日付を記録します |
| サロンの予約表 | スタッフごとの予約を時刻の表で管理します |
| 商品の入出庫と在庫 | 入庫と出庫を記録して現在庫を見ます |
| 個別指導の授業予定と出欠 | 講師と教室と生徒の重なりを防ぐ時間割 |
| 設備の日常点検表 | 設備と日付ごとの点検結果を表で入れます |

見本ごとの限界は、見本の詳細の画面の「この見本でできないこと」に出ます。見本について、くわしくは[くわしい情報](くわしい情報.md#見本のアプリについて)にあります。

## 大事なデータのために

今後の版では、登録したデータを引き継げない場合があります。大事なデータは、一覧の「CSV・Excel に出力する」で保存しておいてください。一覧の出力に入るのは、今の絞り込みの条件に合う行だけです。伝票の明細などが入らないこともあります。

登録したデータを全部残したいときは、次のどちらかにしてください。

- 作ったアプリの左のメニューの「設定・保守」を開き、「データをバックアップする」を押す。登録したデータが 1 つのファイルに保存されます。画面や帳票の設計と、口座番号などを隠して保存する項目（暗号化した項目）を読むための鍵は入りません。戻すときは、同じ「設定・保守」の「バックアップから戻す」を使います
- AiAppMaker を閉じて、アプリのフォルダごと、別の場所へコピーする。中のファイルを選ばず、必ずフォルダごとコピーします。見えないフォルダも一緒にコピーされます

アプリを開いたときに行が 0 件になっていて、消した覚えがないときは、何も登録せずに閉じて、下の「問い合わせ」に連絡してください。

出力に入る範囲のくわしい説明は、[くわしい情報](くわしい情報.md#csv-と-excel-の出力に入る範囲)にあります。

### 同期するフォルダにはアプリを置かないでください

iCloud、OneDrive、Dropbox、Google ドライブなど、同期するフォルダにはアプリを置かないでください。アプリのデータは、使っている間、何度も書き換わります。同期の仕組みが同時に書き換えると、データが壊れることがあります。

2 台のパソコンで同じアプリを同時に開くこともしないでください。アプリは、作ったパソコンで使ってください。

気を付けたいのは、書類フォルダ自体が同期の対象になっている場合です。Mac で iCloud の「デスクトップと書類フォルダ」を使っているときと、Windows で OneDrive のバックアップにドキュメントフォルダを入れているときです。新しいアプリを作るときに、「保存先」を開いて、同期しないフォルダを選んでください。置き場所の変え方は、[困ったとき](困ったとき.md#同期するフォルダに作ったアプリを移す)にあります。

## 困ったとき

データのファイルや鍵のファイルに問題があると、AiAppMaker は空のデータで始めずに、画面に文を出して止まります。次の 3 つのどれかで止まったときは、データを書き換えていません。あわてず、次の手順を見てください。画面の文が「AiAppMaker をダウンロードしたページ」と言っているときも、この 3 つです。

### データのファイルが壊れたとき

画面に「データのファイルが壊れていて、開けません」と出たときです。「バックアップから戻す」のボタンで戻せることがあります。手順は、[困ったとき](困ったとき.md#データのファイルが壊れたとき)にあります。

### データのファイルが見つからないとき

画面に「データのファイルが見つからないか、中身が空です」と出たときです。データのファイルを取り戻す手順は、[困ったとき](困ったとき.md#データのファイルが見つからないとき)にあります。

### 別の PC へ移したアプリが開けないとき

アプリのフォルダを別のパソコンへ移したあとなどに、口座番号などを隠して保存する項目（暗号化した項目）を読むための鍵についての文が出て、開けないときです。手順は、[困ったとき](困ったとき.md#別の-pc-へ移したアプリが開けないとき)にあります。
